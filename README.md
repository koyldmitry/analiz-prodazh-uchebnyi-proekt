Учебный проект по анализу продаж — Excel, сводные таблицы, визуализация данных.
# Анализ продаж интернет-магазина

## Задача
Проанализировать данные о продажах за год (300 заказов, 6 категорий товаров, 5 регионов), 
выявить ключевые закономерности в прибыльности, сезонности и эффективности регионов.

## Инструменты
Excel / Google Таблицы: формулы (СУММЕСЛИ, СЧЁТЕСЛИ, ВПР, ИНДЕКС+ПОИСКПОЗ), 
сводные таблицы, визуализация данных.

## Что сделано
- Построены сводные таблицы: продажи и прибыль по категориям, по месяцам, по регионам
- Добавлены графики для наглядности динамики
- Сформулированы выводы на основе полученных данных

## Выводы
- Категория «Мебель» приносит наибольшую прибыль (155 907,12 ₽) — почти вдвое больше 
  наименее прибыльной категории «Одежда» (85 671,83 ₽)
- Август — месяц с самыми высокими продажами за период
- Регион Казань лидирует по прибыльности среди всех регионов
